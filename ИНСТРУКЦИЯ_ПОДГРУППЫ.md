# Как включить разделы и подгруппы

Код сайта уже поддерживает структуру:

**Основной раздел → Подгруппа → Товар**

Например:

- Горелки
  - Газовые горелки
  - Дизельные горелки
  - Комбинированные горелки
- Запчасти для горелок
  - Насосы для горелок
  - Топочные автоматы
  - Трансформаторы поджига
  - Реле давления
  - Форсунки
  - Электроды поджига и ионизации
  - Датчики пламени
  - Сервоприводы
  - Электромагнитные клапаны
  - Газовые мультиблоки
  - Газовые рампы
  - Прочие запчасти

## 1. Обновите базу Supabase

1. Откройте проект в Supabase.
2. В левом меню выберите **SQL Editor**.
3. Нажмите **New query**.
4. Откройте в проекте файл `supabase/migrations/20260828_catalog_hierarchy.sql`.
5. Скопируйте весь текст файла в SQL Editor.
6. Нажмите **Run**.

Скрипт создаст таблицу разделов, добавит поле подгруппы товара и автоматически
перенесёт существующие газовые, дизельные и комбинированные горелки в нужные
подгруппы. Товары и остальные данные не удаляются.

## 2. Опубликуйте обновлённый код

После выполнения SQL загрузите изменённый проект в GitHub/Vercel тем же способом,
которым публиковали сайт раньше. Переменные окружения Supabase менять не нужно.

## 3. Добавляйте товары

В админ-панели у формы товара появятся два поля:

1. **Основной раздел** — например, «Запчасти для горелок».
2. **Подгруппа** — например, «Насосы для горелок».

На публичном сайте боковое меню автоматически покажет основные разделы,
подгруппы и количество товаров в каждой подгруппе.
